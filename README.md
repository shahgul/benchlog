# benchlog

Personal log for hardware, builds, upgrades, benchmarks and anything else worth tracking over time.

## Folders

| Folder | What's in it |
| --- | --- |
| [`app/`](app/) | Benchlog, a warranty and inventory web app (React and Vite) for everything that plugs in. See its [README](app/README.md). |
| [`pc-build/`](pc-build/) | The phased AM5 desktop build: plan, parts, prices and decisions. |

## Working on the app

```bash
cd app
npm install
npm run dev
```
