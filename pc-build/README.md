# PC build

A phased AM5 desktop for development (Java/Groovy, WSL, Docker, AI agents) and gaming, bought in stages.

## Final target build

| Part | Choice |
|---|---|
| CPU | AMD Ryzen 9 9950X (starting with a Ryzen 5 9600X) |
| Motherboard | Gigabyte B650 Eagle AX |
| RAM | 64 GB DDR5-6000, 2×32 GB (starting with 2×16 GB) |
| SSD | WD Black SN7100 2 TB |
| GPU | NVIDIA RTX 5070 Ti 16 GB |
| PSU | DeepCool 850 W Gold (starting with a PN750M) |
| CPU cooler | Thermalright Peerless Assassin 120 SE |
| Case | NZXT H5 Flow 2024 |
| Monitor | Dell U3225QE |

## Phases

1. Bootable base: 9600X, 32 GB, SN7100 2 TB, iGPU for display.
2. Graphics: RTX 5070 Ti-class GPU and a suitable PSU.
3. Development horsepower: Ryzen 9 9950X and 64 GB as 2×32 GB.
4. Display: a 32-inch 4K high-refresh main monitor.
